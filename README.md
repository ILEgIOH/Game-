# BeatForge

Ритм-игра в браузере (как osu!mania): загружаешь свой трек, игра анализирует аудио и сама расставляет ноты.

Запуск: открыть `index.html` в Chrome/Firefox/Edge.

- 4–7 дорожек, клавиши переназначаются на экране перед игрой (Esc — пауза, ` — рестарт)
- Анализ: спектральный flux + адаптивный порог, оценка BPM и сетка битов (ноты привязываются к сетке, на сложной добираются пропущенные доли)
- Библиотека: треки и результаты анализа сохраняются в браузере (IndexedDB), рекорды — отдельно для каждого числа дорожек и сложности
